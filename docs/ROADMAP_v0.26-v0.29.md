# 世界神话系统故事阅读路线图：v0.26–v0.29

本路线图从 v0.25 的来源约束故事层继续扩张。版本号表示可验收的阶段，不代表世界神话资料会在某个版本“全部完成”。

## v0.26 — 故事地图与阅读路线

- 新增故事事件节点、章节顺序与地点连接；神话地点不强制投射为现实坐标。
- 提供“创世”“冥界之旅”“神战”“神器流转”“谱系冲突”等主题阅读路线。
- 从故事段落进入关系图、事件档案和有证据坐标的现实遗址。
- 验收重点：路线顺序可复现、版本边界不丢失、手机导航不裁切。

## v0.27 — 原典见证对读

- 对同一故事的独立见证做分段对照，不把差异整理成虚构的统一文本。
- 显示原文名、转写、语言、来源定位、编辑说明与逐段证据状态。
- 首批重点：阿佛洛狄忒出身、Ask／Embla 创造见证、巴力叙事、雷神同名与地方版本。
- 验收重点：每个差异能回到来源或显式未知项；现代译本版权边界保持清楚。

## v0.28 — 全球故事扩张批次

状态：v0.28.0 已于 2026-09-01 正式封存；后续扩张继续沿永久队列推进。

- 从永久队列选择资料缺口明确、权威来源可得且扩张价值高的传统。
- 优先扩张 Maya、Yorùbá、Māori、中国、日本、印度与东南亚故事；活态传统先核对授权与社区语境。
- 新实体、名称、语言、事件、文本、遗址、器物、Claims、Evidence 和冲突只追加，不按名称合并。
- 验收重点：每批局部失败进入审计，其余目标继续；不把现代改编当古代事实。

首批结果：

- 已完成：Maya 英雄双子／七金刚鹦鹉公开 K'iche' 语境事件、日本草薙剑双来源层、吴哥寺乳海搅拌物质见证。
- 已排队：中国女娲补天的古典文本分见证、印度乳海搅拌文本见证审计。
- 权限阻塞：Māori 具名 iwi／hapū 版本与 Yorùbá／Ifá 内容扩张；阻塞只属于对应目标，不撤销已完成故事。
- 正式检查点保留全部 7 个目标的状态；“正式发布”不等于全部目标完成。

## v0.29 — 阅读器与离线档案

状态：v0.29.0 已于 2026-09-02 完成正式封版；后续故事与阅读体验扩张进入下一版路线。

- 增加本地书签、阅读进度、术语表、人物速查和无障碍阅读设置。
- 提供离线可用、适合打印的故事档案，并保留来源、证据和许可说明。
- 阅读状态默认只存本机，不进入公开数据库，也不收集个人阅读行为。
- 验收重点：离线档案与 SQLite／JSONL／CSV 检查点一致，键盘与手机操作可用。

正式封版结果：

- 本机状态使用版本化 `wms-reader-v029` 键，仅保存故事 ID、分段进度与显示设置；没有账号、遥测或云同步。
- 阅读器已经加入字号、行距、高对比、主题术语、人物／文本／器物速查、当前故事打印与本机书签标识。
- 生成双语单文件 HTML 与可检查 JSON；两者均来自浏览器安全故事快照，保留来源、定位、证据说明与第三方权利边界。
- Migration 39 只登记功能与隐私契约，Migration 40 封存 `release.v0.29.0`；两者都不把个人阅读行为写入 SQLite、JSONL、CSV 或公开网页数据。

每个版本完成后均运行完整数据库验证、外键与完整性检查、来源与隐私检查、全表导出、生产网页构建、回归测试、Git bundle 与 ZIP 校验，并刷新 GitHub Pages。
