# 研究、来源与真实性方法

## 一条事实的生命周期

1. 新名称或线索进入 `collection_queue`，保留发现来源与语境。
2. 建立稀疏实体；找不到的字段保持空值。
3. 找到文本、物件、遗址、口述传统或学术来源并登记 `sources`。
4. 把具体说法写成 `claims`，注明它属于神话叙事、历史现实、学术解释还是现代猜想。
5. 用 `evidence` 连接到精确章节、行号、馆藏号、手稿号或遗址记录。
6. 冲突版本共同保留；不覆盖、不强行选唯一答案。
7. 质量检查通过后更新为阶段性 baseline；队列继续增长。

## 来源优先级

系统优先发现原始文本、学术校勘本、博物馆、大学、国家图书馆、考古机构、UNESCO、官方遗址资料和学术论文。普通网页可以帮助发现线索，但重要 claim 应回到更稳定的来源。

“来源等级”只表示来源身份和与材料的距离，不自动决定某项解释是真的。例如：古代史诗可高置信证明“这篇史诗如此叙述”，却不能证明超自然事件在现实历史中发生。

## 来源登记与联网核验

来源状态严格分层：

- `REGISTERED`：至少有可复查的 URL、DOI、ISBN、馆藏号或手稿号之一，但尚未完成 URL 语法或联网检查。
- `URL_SYNTAX_VALID`：只说明 HTTP(S) URL 结构有效；不说明服务器可达、页面内容匹配或来源结论正确。
- `WEB_CONFIRMED`：除有效 URL 外，`notes` 中必须保留 `VERIFICATION_RECEIPT_JSON`，至少包含 `checked_at`、`method`、`locator`、`outcome`，且 outcome 为 `REACHABLE`。
- `NEEDS_REVIEW` / `UNAVAILABLE`：定位或可达性存在待解决问题。

`accessed_date` 是来源登记的访问日期字段，不单独充当成功回执。网页会改变；回执只证明当时的检查动作和结果。每次报告都会生成完整 `reports/source_registry.md`，逐条公开状态、定位符、文化语境和权限限制，避免用一个汇总数字代替核验记录。

## 文本作品、见证和数字入口

以下三层不能混合：

- 抽象作品：《神谱》《诗体埃达》《亡灵书》语料传统。
- 具体见证：某份手稿、泥板、纸草或版本。
- 数字入口：图书馆、博物馆或学术平台提供的访问 URL。

Getty 与 Library of Congress 对同一《佛罗伦萨手抄本》的入口会通过 `same_witness_as_source_id` 连接，不被计为两个独立文本证人。

## 文明和版本边界

- Inanna 与 Ishtar 可以建立有来源的 `IDENTIFIED_WITH` 关系，但不会删成一个实体。
- Ugaritic Baal 与其他地区以 `baal` 为称号的神不会按名称自动合并。
- Norse、Germanic、Anglo-Saxon；Aztec、Mexica；Vedic、Hindu；Celtic、Irish、Welsh 均保留各自语境。
- 五行、印度五大、希腊元素和比较词汇分别建实体；`COMPARABLE_TO` 不等于 `IDENTIFIED_WITH`。

## 考古、神话地点与后世传说

`place_profiles.reality_status` 明确区分现实考古遗址、现实圣地、现实历史城市、神话地点、后世传说、现代猜想和混合地点。Newgrange 的新石器时代考古层不能因为后世爱尔兰传说而自动归属于某位命名凯尔特神。

## 活态与原住民传统

Ifá、毛利、夏威夷和其他活态传统不能被当作“无人拥有的网页资料”。来源可记录：

- 社群或传承谱系；
- 资料是否神圣、受限或需许可；
- 收集者的殖民、传教或行政语境；
- 当代传承人和机构的说明；
- 是否允许复制、再发布或训练用途。

没有古代手稿不等于低可信；它可能是口述传统本身的媒介特征。系统不会声称已抓取“完整 Ifá corpus”。

## 现代改编

电影、游戏、漫画和网络文化建立独立现代实体，再用 adaptation 边连接古代原型。Marvel Thor 的能力不属于古诺斯 Thor 的原始 claim。

## 版权

现代受版权保护书籍不复制全文。仅保存书目、版本、章节定位、合规短摘录和研究摘要。数字影像和博物馆图片的再使用遵守各机构条款。

## 永不使用 ALL COMPLETE

Coverage 只报告当前登记资料中的计数与缺口，不计算“世界神话完成百分比”。正确结论始终是：当前公开可发现资料的阶段性知识基线已经建立，并且系统可以继续扩张。
