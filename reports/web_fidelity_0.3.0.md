# 公开探索器设计一致性与浏览器 QA

版本：`v0.3.0-public-preview`  
检查日期：2026-08-13

## 结果

桌面端与手机端浏览器自动化检查通过，共 18 项：中文默认语言、真实指标、实体载入、搜索、导航五个视图、中英文切换、移动导航、移动详情抽屉和水平溢出。桌面与手机的 `documentElement.scrollWidth - innerWidth` 均为 `0px`；控制台、页面异常和请求失败均为 0。

检查环境没有预装中文浏览器字体，因此项目加入了自托管、按 Unicode 分段加载的 `Noto Sans SC Variable`，保证截图与 GitHub Pages 都能正确显示中文。

## 设计对照账本

| 对照点 | 概念稿 | 实装结果 | 结论 |
|---|---|---|---|
| 视觉系统 | 深海军蓝、古金线框、星点纹理、蓝色关系光线 | 同一配色、边框、星点背景与蓝色图谱；减少装饰以提升可读性 | 一致 |
| 首屏结构 | 品牌／导航 → 搜索与四指标 → 筛选／实体／详情三栏 | 完整保留，指标来自 SQLite 快照 | 一致 |
| 中文优先 | 中文标题、导航、字段与动作；可切换 EN | `zh-Hans` 默认，完整中英文切换并持久化选择 | 一致 |
| 实体详情 | 名称、原文、状态、别名、关系图、证据与纠错动作 | 全部实装；只展示数据库存在的内容，不用概念稿占位说明 | 一致且更真实 |
| 手机结构 | 搜索、指标、筛选、实体列表与底部详情抽屉 | 响应式列表、导航菜单、88vh 底部抽屉与遮罩完整实装 | 一致 |
| 公开证据边界 | 概念稿含示例短引文 | 实装只公开摘要、来源和定位，不批量导出 `short_quote` | 有意偏离：版权与复用安全 |
| 数量口径 | 概念稿列表显示 430 | 顶部保留 430 注册实体；列表显示 425 个去重后的规范实体 | 有意偏离：避免 redirect 重复 |
