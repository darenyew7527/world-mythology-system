# v0.25.0 阅读界面验证记录

## 目标流程

“神话故事”导航 → 选择故事 → 切换文本版本 → 打开相关实体／权威来源；预期正文、证据边界与 URL 中的故事状态一致，桌面和手机都不依赖未公开数据。

## 验证环境

- 生产构建：Vite 8.2.1，React 19.2.8，构建成功。
- 自动回归：172 项 Python／数据／前端结构测试通过。
- 专用 Browser Plugin：当前运行环境未提供。
- 本地 Playwright：运行时包存在，但没有已安装的 Chromium 可执行文件；未下载新浏览器依赖，因此本检查点没有伪称实机截图或控制台验收。
